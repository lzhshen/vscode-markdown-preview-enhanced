# Mermaid 图缩放 / 拖拽 — 产品需求

> 状态：已实现并在 VSCode 中验证（代码：`media/mermaid-zoom.js`、`media/mermaid-zoom.css`；手动测试文档：`test/markdown/test-mermaid-zoom.md`） · 原型：[prototype.html](prototype.html)（浏览器直接打开）

## 1. 背景

大一些的 Mermaid 流程图、时序图在预览里会被压缩到预览栏宽度，文字小到看不清，而目前预览里既不能放大，也不能平移查看局部。

## 2. 目标与非目标

**目标**

- 在 VSCode 预览中，Mermaid 图支持放大、缩小、拖拽平移。
- 提供"全屏"查看大图。
- 不改变现有用户看到的初始效果，不打断正常的页面滚动与编辑。

**非目标（本期不做）**

- 其他图表（PlantUML、GraphViz、D2、WaveDrom、Vega 等）和普通图片。实现上要做成通用组件，方便下一期推广。
- 导出产物（HTML / PDF / Pandoc / 电子书）中的交互：导出保持静态图。
- 复制 SVG、下载 PNG 等导出按钮。
- 把视图状态持久化到磁盘。

## 4. 交互规格

### 4.1 行内（文档中的图）

- **外观**：初始渲染与现在逐像素一致。鼠标悬停时，图的容器出现淡边框，右上角淡入工具栏；键盘焦点落在工具栏内时，工具栏也保持显示。
- **工具栏**：`−` | `100%` | `+` | 适应 | 全屏。
  - `−` / `+`：以容器中心为锚点，缩放 ÷1.2 / ×1.2，带 180ms 过渡动画。
  - 百分比：实时显示当前缩放比例，点击恢复到 100% 并清零位移。
  - 适应：缩放并居中，让整张图完整显示在容器内，四周留 16px 边距。
  - 全屏：打开 4.2 的浮层。
- **缩放**：`Ctrl`/`⌘` + 滚轮，或触控板捏合，以光标位置为锚点，不带过渡动画。缩放时阻止页面滚动；不按修饰键时完全不拦截滚轮。
- **拖拽**：左键按下后移动超过 4px 开始平移，光标变为 `grabbing`；在任何缩放比例下都可以拖。拖拽结束后，紧接着的那次 click 会被吞掉，避免误触节点链接。
- **双击**：双击在空白处（不在节点、连线标签或链接上）时恢复 100%。
- **容器**：高度等于图原本的高度，`overflow: hidden`。缩放和平移都不会让文档布局跳动。

### 4.2 全屏浮层

- 铺满预览面板，四周是半透明遮罩，中间是图的画布；打开时自动"适应"。
- 默认（`mermaidZoomFullscreen: "screen"`）同时占满整个屏幕：VS Code 进入禅模式（`zenMode.fullScreen` 默认开启，即系统全屏），有多个编辑器分组时再最大化预览所在分组；关闭浮层时依次恢复。窗口放大过程中图会持续重新适应，直到用户开始缩放或拖拽。
- 全屏和行内的状态互相独立，关闭后行内视图不受影响。
- 全屏里没有页面滚动冲突，所以**滚轮直接缩放**，不需要按修饰键。
- 工具栏常驻显示，比行内多一个"关闭"按钮。底部有一行操作提示。
- 快捷键：

  | 键        | 动作                           |
  | --------- | ------------------------------ |
  | `+` / `=` | 放大                           |
  | `-`       | 缩小                           |
  | `0`       | 100%                           |
  | `F`       | 适应                           |
  | 方向键    | 平移 50px                      |
  | `Esc`     | 关闭，焦点回到打开前的全屏按钮 |

### 4.3 编辑时的状态保持

- 视图状态 `{scale, x, y}` 以「第几个 Mermaid 代码块」为键，存在预览页的内存里。
- 预览重渲染（输入、保存、切换主题）后，同序号的图恢复原来的状态。
- 增删图会导致序号错位，这是可以接受的已知行为：错位后的图只是沿用了别的图的视图，用户点一下百分比就能恢复。

### 4.4 配置

- `markdown-preview-enhanced.enableMermaidZoom`（boolean，默认 `true`）。关闭后与现在的行为完全一致。
- 代码块属性 `{data-zoom=false}`：只对这一个图关闭交互。

## 5. 边界情况

- **渲染失败**：Mermaid 报错时显示原有的错误信息，不包缩放层。
- **主题切换 / 深色模式**：工具栏和遮罩的颜色跟随预览主题。
- **预览宽度变化**：100% 状态下图跟着容器自适应（保持现在的行为）；非 100% 状态下保持当前的缩放和位移。
- **同一页多个图**：每个图有各自独立的状态。
- **滚动同步**：缩放层不能改变图的布局高度，否则编辑器和预览的滚动同步会错位。
- **`{code_block=true}`、导出、`{filename=...}`**：都不受影响。

## 6. 验收标准

1. 开关打开时，未操作过的 Mermaid 图截图与改动前完全一致。
2. 不按修饰键滚动鼠标滚轮经过图时，页面正常滚动，图不缩放。
3. `⌘`/`Ctrl` + 滚轮、触控板捏合，都以光标为中心缩放，范围被限制在 10%–1000%。
4. 拖拽 ≥4px 会平移且不触发节点点击；单击节点仍然触发 `click` 链接或回调。
5. 在源码里编辑这个图之后，它的缩放和位移保持不变。
6. 全屏浮层里，所有快捷键可用，`Esc` 关闭后焦点回到原按钮。
7. `enableMermaidZoom: false` 或 `{data-zoom=false}` 时，行为与现在一致。
8. 导出 HTML / PDF 时，图中不含工具栏或变换样式。

## 7. 实现方案

- **做成扩展注入预览的独立脚本**，和扩展现有的图片灯箱（`media/lightbox.js`）同一种做法：`media/mermaid-zoom.js` 和 `media/mermaid-zoom.css`，由 `src/preview-provider.ts` 在 `enableMermaidZoom` 开启时注入预览的 `<head>`。不用改 crossnote；导出走的是另一条生成流程，天然不会带上这个脚本。
- 用 `MutationObserver` 监听预览的 DOM 变化，每帧最多扫描一次，给 `div.mermaid` 下直接的 `<svg>` 包上 `viewport > stage` 两层。包裹时**移动**原有节点，不重建。
- 用 CSS `transform: translate() scale()` + `transform-origin: 0 0` 实现缩放。100% 时完全不设 `transform`，保证和改动前逐像素一致。
- 预览本来就在 `document` 的捕获阶段用 Ctrl/⌘ + 滚轮缩放整页，所以图上的滚轮监听要注册在 `window` 的捕获阶段，才能抢先处理。
- 预览的整页缩放用的是 CSS `zoom`，所以鼠标坐标要先换算回视口内的坐标。全屏浮层带上 `fixed` 类，让预览在整页缩放时自动对它做反向缩放。
- 视图状态按「第几个 `div.mermaid`」存在脚本的内存里，跨重渲染保留，webview 重新加载后清空。
- **实现中踩到的坑**：
  - 图里的链接默认可以被浏览器原生拖放，一旦触发 `dragstart` 就会取消指针事件，平移也随之中断，所以要在视口上阻止 `dragstart`。
  - 预览容器本身的背景是透明的，全屏画布要往上找第一个不透明的背景色，否则底下的预览内容会透上来。
  - webview 不允许使用浏览器的 Fullscreen API（iframe 没有 `fullscreen` 权限），所以整屏全屏只能由扩展执行 VS Code 命令：浮层打开 / 关闭时向扩展发 `setMermaidScreenFullscreen` 消息，扩展在 `src/mermaid-zoom.ts` 里执行 `workbench.action.toggleZenMode`、`workbench.action.toggleMaximizeEditorGroup` 和 `workbench.action.exitZenMode`。
  - `acquireVsCodeApi()` 每个页面只能调用一次，且预览自己已经调用了。脚本因此不加 `defer`，在预览脚本之前把它包装成"缓存第一次结果"的版本，两边共用同一个实例。
  - 扩展读不到当前是否已经处于禅模式；如果打开全屏前已在禅模式，关闭时会一并退出。预览重新加载或面板关闭时扩展也会退出全屏，避免残留。
  - 原型里提到的 `bindFunctions` 问题不影响实际插件：crossnote 本来就没有调用 `bindFunctions`，只要包裹时移动原有节点即可。

## 8. 原型里我自行补的决策（如有异议请提出）

- 全屏里滚轮不需要修饰键就直接缩放。
- 全屏里的百分比是相对 SVG 原始尺寸（viewBox）计算的；行内的百分比是相对初始显示尺寸。
- 工具栏按钮带 `aria-label` 和 `title` 提示。
- 不专门处理触摸屏（VSCode 是桌面端）。
- 鼠标在图上时，Ctrl/⌘ + 滚轮缩放这张图，不再缩放整页；在图外仍然缩放整页。
- 演示模式（reveal.js 幻灯片）里不启用。
